# 3MF 多色打印导出说明

## 什么是 3MF？

3MF (3D Manufacturing Format) 是一种现代化的 3D 打印文件格式，由微软主导开发，相比传统的 STL 格式有以下优势：

- ✅ **原生支持多材质/多颜色**
- ✅ **单个文件包含所有部件**
- ✅ **保留颜色和材质信息**
- ✅ **文件体积更小**
- ✅ **支持元数据和缩略图**

## 使用方法

### 1. 导出 3MF 文件

在软件中：
1. 生成你的键帽模型
2. 点击菜单 `文件 -> 导出3MF(M) [推荐多色]` 或按 `Ctrl+M`
3. 选择保存位置并命名

### 2. 导入切片软件

支持 3MF 格式的主流切片软件：
- **Bambu Studio** (拓竹打印机)
- **PrusaSlicer** (Prusa 打印机)
- **Cura** (Ultimaker 及通用)
- **Simplify3D**

直接将 `.3mf` 文件拖入切片软件即可。

### 3. 设置多色打印

导入后，你会看到两个独立的部件：
- **Keycap** (按键主体 - 默认深灰色)
- **Text** (文字 - 默认白色)

在切片软件中：
1. 选中 `Keycap` 部件 → 指定主体颜色/材料
2. 选中 `Text` 部件 → 指定文字颜色/材料
3. 切片并打印

## 依赖安装

3MF 导出功能需要 `trimesh` 库支持。

如果导出失败，请在终端运行：
```bash
pip install trimesh
```

## 对比其他格式

| 格式 | 多色支持 | 文件数量 | 对齐难度 | 推荐度 |
|------|---------|---------|---------|--------|
| 3MF  | ✅ 原生 | 1个     | 自动    | ⭐⭐⭐⭐⭐ |
| STL  | ❌ 需手动 | 2个    | 需手动  | ⭐⭐⭐ |
| STEP | ⚠️ 部分  | 2个    | 需手动  | ⭐⭐⭐⭐ |

**推荐优先使用 3MF 格式进行多色打印！**
