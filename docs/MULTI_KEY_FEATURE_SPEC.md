# 多按键批量生成功能说明文档

## 1. 功能概述

为了解决用户需要逐个生成按键并逐个导入切片软件的繁琐流程，本功能将引入"多按键生成模式"。该模式允许用户基于一套统一的键帽几何参数（如高度、形状、轴体），批量定义和生成多个按键（如整个键盘的字母区），并支持一次性导出或生成排列整齐的3D模型。

## 2. 核心概念重构

为了支持此功能，底层数据模型将进行如下重构：

### 2.1 参数分离
将原本混合的 `KeycapParameters` 拆分为：
1.  **键帽几何参数 (KeycapGeometryParams)**: 
    *   包含所有物理形状相关的设置。
    *   例如：宽度、高度、深度、壁厚、倒角、轴体类型、高度预设 (Cherry/OEM等)。
    *   *特点*：在批量生成中，这部分参数通常是**全局统一**的（虽然也可以允许特例，但主要作为基准）。

2.  **字符参数 (CharacterParams)**:
    *   包含单个字符的所有视觉设置。
    *   例如：字符内容、字体、字号、位置(X/Y)、旋转角度、深度、颜色（用于多色打印）。
    *   每个按键可以包含 **0到5个** 字符对象。

3.  **单键设计 (KeycapDesign)**:
    *   组合了 1个 `KeycapGeometryParams` 和 N个 `CharacterParams`。
    *   代表一个具体的按键设计（例如 "A" 键）。

4.  **多键项目 (MultiKeyProject)**:
    *   包含全局几何设置。
    *   包含按键阵列定义（行数、列数、间距）。
    *   包含按键列表（每个位置对应的字符设置）。

## 3. 用户界面 (UI) 交互设计

主界面将引入模式切换或标签页，分为 **"单键设计模式"** 和 **"批量阵列模式"**。

### 3.1 单键设计模式 (现有功能的增强)
*   保持现有布局：左侧参数，右侧预览。
*   **改进**：左侧面板明确区分 "键帽形状设置" 和 "字符内容设置"。
*   **字符管理**：支持添加多个字符（Tab页或列表形式），每个字符独立设置字体、大小、位置。
*   **模板保存**：用户可以将当前设置保存为模板（例如 "R3-字母键标准"）。

### 3.2 批量阵列模式 (新功能)
*   **左侧设置面板**：
    *   **阵列设置**：行数 (Rows)、列数 (Cols)、行间距 (Row Spacing)、列间距 (Col Spacing)。
    *   **全局几何覆盖**：允许在此处修改所有按键共用的几何参数（引用单键模式的几何设置）。
    *   **操作按钮**：全部生成、导出所有、重置。

*   **右侧视图区域**：
    *   **上方 2D 阵列预览**：
        *   显示 R x C 的网格。
        *   每个格子代表一个按键。
        *   显示按键上的字符预览。
        *   **交互**：
            *   **双击** 某个格子：弹出 **"按键字符编辑器"** 对话框。
            *   **右键** 某个格子：复制、粘贴、清除、禁用（不生成该位置）。
            *   **拖拽**：支持从一个格子拖拽属性到另一个格子（可选）。
    *   **下方 3D 整体预览**：
        *   显示生成后的按键矩阵盘。
        *   支持实时更新（当修改单个按键字符后）。

### 3.3 按键字符编辑器 (弹窗/Dialog)
*   当用户在批量模式下双击某个按键时弹出。
*   **内容**：
    *   输入框：字符1、字符2... (支持最多5个)。
    *   每个字符的微调参数（偏移、大小）。
    *   默认继承全局设置，但允许覆盖。
*   **快捷操作**：支持 Tab 键快速切换到下一个按键，方便连续输入（如输入 A -> Tab -> B -> Tab -> C）。

## 4. 导出功能
*   **单文件导出**：将整个阵列导出为一个 STL/STEP/3MF 文件（方便一次性打印）。
*   **分离导出**：将每个按键导出为独立文件，自动命名（如 `Key_1_1_A.stl`, `Key_1_2_B.stl`）。

## 5. 实现步骤

1.  **数据结构重构**：修改 `core/parameters.py`，实现参数分离。
2.  **单键逻辑适配**：更新现有 UI 和生成器适配新的数据结构。
3.  **多键 UI 框架**：实现主界面的模式切换和网格布局参数。
4.  **2D 网格交互**：实现自定义 Widget 绘制按键网格，处理点击事件。
5.  **字符编辑弹窗**：实现快速录入字符的对话框。
6.  **批量生成逻辑**：编写循环调用核心生成器的逻辑，并组合结果。
7.  **导出功能升级**：支持阵列模型的合并导出。
