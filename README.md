# 机械键盘按键模型生成器

一个参数化的机械键盘按键（键帽）3D模型生成器，支持自定义字体、字母、按键尺寸和斜角等参数，生成分离的按键本体和文字模型，便于多色3D打印。

## 功能特性

- 🎨 自定义字体和字母
- 📐 参数化按键尺寸（宽度、高度、深度）
- 🔺 可调节斜角（顶部、侧面）
- 🔤 独立的文字模型生成（便于多色打印）
- 👁️ 实时3D预览
- 💾 支持STL和STEP格式导出
- 🔧 支持多种轴体类型（MX、Alps等）

## 技术栈

- **GUI**: PyQt5
- **3D建模**: CadQuery
- **3D预览**: VTK
- **字体处理**: fontTools + shapely

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行

```bash
python main.py
```

## 使用说明

1. 选择字体和输入字母
2. 设置按键尺寸参数（宽度、高度、深度）
3. 调整斜角参数
4. 设置文字参数（高度、深度）
5. 点击"生成模型"预览
6. 导出STL或STEP文件
